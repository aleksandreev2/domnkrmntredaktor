# Редактура «Дом Некроманта»

Закрытая платформа для чтения, совместной вычитки и модерации правок переводов.

Проект строится как бесплатный full-stack web app на Cloudflare Workers + React/Vite + D1 с отдельным Google Drive bridge для синхронизации глав.

> Репозиторий инициализирован. Основная разработка ведётся через feature-ветки и pull request.
